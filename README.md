# Разработка интернет-приложений (РИП) 2025

## Оптимизатор запросов к базе данных

Разработанное приложение позволит аналитикам создавать и формировать заявки на расчёт времени выполнения SQL-запроса с выбранными ими индексами, а администраторам БД завершать или отклонять данные заявки.
